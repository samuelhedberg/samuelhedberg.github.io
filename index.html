Introduktion

Hur fungerar Claude Code?

Claude Code är ett kommandoradsverktyg från Anthropic som låter AI-modellen Claude läsa, skriva och köra kod direkt i dina egna projekt — som en kollega som kan programmera, men som du styr via vanligt språk.

Vad är Claude Code?

Istället för att bara chatta med en AI och klistra in kod manuellt, kör Claude Code i din terminal (eller i en app) och jobbar direkt mot dina filer. Du beskriver vad du vill ha gjort — "lägg till en login-sida", "fixa den här buggen", "skriv tester" — och Claude utför jobbet steg för steg.

Det är byggt för riktiga utvecklingsprojekt: det förstår projektstruktur, kan söka i kodbasen, köra terminalkommandon och arbeta med Git — allt med din tillåtelse.

Så går en uppgift till

1

Du beskriver vad du vill

I vanligt språk, t.ex. "skapa en enkel kontaktformulär-sida" eller "hitta varför testerna failar".

2

Claude utforskar och planerar

Den läser relevanta filer, söker i koden och bygger upp en förståelse för projektet innan den agerar.

3

Claude använder verktyg

Den kan skriva och redigera filer, köra kommandon i terminalen, köra tester och använda Git — steg för steg.

4

Du granskar och godkänner

Känsliga eller svåra att ångra steg (som att skicka kod eller radera filer) kräver ditt godkännande.

5

Resultatet levereras

Du får fungerande kod, en förklaring av vad som gjorts, och kan be om justeringar direkt.

Vad kan man använda det till?

Bygga nya funktioner

Beskriv funktionen, Claude skriver koden i ditt projekts stil och struktur.

Hitta och fixa buggar

Claude kan läsa felmeddelanden, söka i koden och föreslå eller göra en fix.

Förstå okänd kod

Be Claude förklara hur en fil eller ett system hänger ihop innan du ändrar något.

Skriva tester & dokumentation

Automatisera det tråkiga arbetet som annars ofta blir bortprioriterat.

Hur kommer man igång?

Claude Code installeras som ett kommandoradsverktyg och körs i mappen för ditt projekt med kommandot claude. Därifrån skriver du helt enkelt vad du vill ha gjort.
